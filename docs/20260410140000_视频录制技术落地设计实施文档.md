## 一、实施总览

### 1.1 目标

在现有 GIF 录制能力基础上，新增**视频录制（MP4）**功能。采用可行性分析中确定的**方案 E（FFmpeg 按需下载）**，核心原则：

- 安装包零膨胀（FFmpeg 不内嵌）
- 首次使用视频录制时引导下载 FFmpeg（~30MB，一次性）
- 无 FFmpeg = 无法录视频，截屏和 GIF 不受影响
- 两阶段录制：帧捕获（PNG 序列）→ FFmpeg 编码（MP4）
- 最大复用 GIF 录制架构（`RecordingSession` 状态机、`SelectionOverlay`、`RecordBar`）

### 1.2 开发成本预估

| 模块 | 预估工时 | 复用程度 |
|------|---------|---------|
| config.rs 扩展 | 0.5h | 改动量小 |

| CI/构建验证 | 1h | 无变化，仅验证 |
| 测试（Win + macOS） | 3h | — |
| **合计** | **~19h（约 2.5 人天）** | |

### 1.3 新增依赖

| crate | 用途 | 影响 |
|-------|------|------|
| `reqwest` (features: `stream`, `rustls-tls`) | HTTP 下载 FFmpeg 压缩包 | Cargo 依赖新增，包体积 +~500KB |
| `zip` | 解压 FFmpeg 压缩包（Windows/macOS） | 轻量 |
| `tokio` (features: `rt-multi-thread`, `fs`) | 异步下载 + 文件 IO | Tauri 2.x 已内置 tokio runtime，仅显式引入 features |
| `futures-util` (features: `io`) | 流式下载进度 | 轻量 |

> **注意**：不引入任何视频编码 crate（openh264、ffmpeg-next 等），编码完全由外部 FFmpeg 进程完成。

```rust
// video/ffmpeg_manager.rs

use std::path::PathBuf;
use crate::config::ConfigManager;

const FFMPEG_VERSION: &str = "7.1";

/// 获取 ffmpeg 可执行文件路径
pub fn get_ffmpeg_path() -> PathBuf {
    let bin_dir = ConfigManager::base_dir().join("bin");
    if cfg!(target_os = "windows") {
        bin_dir.join("ffmpeg.exe")
    } else {
        bin_dir.join("ffmpeg")
    }
}

/// 检查 ffmpeg 是否已安装（文件存在 + 可执行验证）
pub fn is_ffmpeg_available() -> bool {
    let path = get_ffmpeg_path();
    if !path.exists() { return false; }

    // 验证可执行：运行 ffmpeg -version
    std::process::Command::new(&path)
        .arg("-version")
        .stdout(std::process::Stdio::null())
        .stderr(std::process::Stdio::null())
        .status()
        .map(|s| s.success())
        .unwrap_or(false)
}

/// 获取 ffmpeg 版本号（从 ffmpeg.version 文件读取）
pub fn get_installed_version() -> Option<String> {
    let version_file = ConfigManager::base_dir().join("bin").join("ffmpeg.version");
    std::fs::read_to_string(version_file).ok()
        .map(|s| s.trim().to_string())
}

/// 获取平台对应的下载 URL
fn get_download_url() -> &'static str {
    if cfg!(target_os = "windows") {
        "https://www.gyan.dev/ffmpeg/builds/ffmpeg-release-essentials.zip"
    } else if cfg!(target_os = "macos") {
        "https://evermeet.cx/ffmpeg/ffmpeg-7.1.zip"
    } else {
        "https://johnvansickle.com/ffmpeg/releases/ffmpeg-release-amd64-static.tar.xz"
    }
}

/// 获取备用下载源（主源失败时切换）
fn get_mirror_urls() -> Vec<&'static str> {
    // GitHub Releases 镜像作为备选
    if cfg!(target_os = "windows") {
        vec!["https://github.com/BtbN/FFmpeg-Builds/releases/download/latest/ffmpeg-master-latest-win64-gpl.zip"]
    } else if cfg!(target_os = "macos") {
        vec!["https://github.com/BtbN/FFmpeg-Builds/releases/download/latest/ffmpeg-master-latest-macOS-gpl.zip"]
    } else {
        vec!["https://github.com/BtbN/FFmpeg-Builds/releases/download/latest/ffmpeg-master-latest-linux64-gpl.tar.xz"]
    }
}
```

#### 3.2.3 下载流程

```rust
use tauri::{AppHandle, Emitter};
use std::io::Write;

/// 下载 FFmpeg 到 ~/.sip-cc/bin/
/// 通过 Tauri 事件向前端推送下载进度
pub async fn download_ffmpeg(app: AppHandle) -> Result<PathBuf, String> {
    let bin_dir = ConfigManager::base_dir().join("bin");
    std::fs::create_dir_all(&bin_dir)
        .map_err(|e| format!("创建 bin 目录失败: {e}"))?;

    let urls = std::iter::once(get_download_url())
        .chain(get_mirror_urls().into_iter());

    let mut last_err = String::new();

    for url in urls {
        match try_download(&app, url, &bin_dir).await {
            Ok(path) => {
                // 写入版本文件
                let version_file = bin_dir.join("ffmpeg.version");
                let _ = std::fs::write(&version_file, FFMPEG_VERSION);
                return Ok(path);
            }
            Err(e) => {
                last_err = e;
                let _ = app.emit("ffmpeg-download-error", &last_err);
                continue;
            }
        }
    }

    Err(format!("所有下载源均失败: {last_err}"))
}

async fn try_download(app: &AppHandle, url: &str, bin_dir: &PathBuf) -> Result<PathBuf, String> {
    let client = reqwest::Client::builder()
        .timeout(std::time::Duration::from_secs(300))
        .build()
        .map_err(|e| format!("HTTP 客户端初始化失败: {e}"))?;

    let resp = client.get(url).send().await
        .map_err(|e| format!("请求失败: {e}"))?;

    let total_size = resp.content_length().unwrap_or(0);
    let _ = app.emit("ffmpeg-download-start", total_size);

    // 流式下载到临时文件
    let tmp_path = bin_dir.join("ffmpeg_download.tmp");
    let mut file = std::fs::File::create(&tmp_path)
        .map_err(|e| format!("创建临时文件失败: {e}"))?;

    let mut downloaded: u64 = 0;
    let mut stream = resp.bytes_stream();

    use futures_util::StreamExt;
    while let Some(chunk) = stream.next().await {
        let chunk = chunk.map_err(|e| format!("下载中断: {e}"))?;
        file.write_all(&chunk).map_err(|e| format!("写入失败: {e}"))?;
        downloaded += chunk.len() as u64;
        let _ = app.emit("ffmpeg-download-progress", (downloaded, total_size));
    }
    drop(file);

    // 解压
    extract_ffmpeg(&tmp_path, bin_dir)?;

    // 清理临时文件
    let _ = std::fs::remove_file(&tmp_path);

    // macOS/Linux: 设置可执行权限
    #[cfg(not(target_os = "windows"))]
    {
        let ffmpeg_path = get_ffmpeg_path();
        std::process::Command::new("chmod")
            .args(["+x", &ffmpeg_path.to_string_lossy()])
            .status()
            .ok();

        // macOS: 移除隔离属性
        #[cfg(target_os = "macos")]
        {
            std::process::Command::new("xattr")
                .args(["-cr", &ffmpeg_path.to_string_lossy()])
                .status()
                .ok();
        }
    }

    Ok(get_ffmpeg_path())
}
```

#### 3.2.4 解压逻辑

```rust
fn extract_ffmpeg(archive_path: &PathBuf, bin_dir: &PathBuf) -> Result<(), String> {
    let ext = archive_path.to_string_lossy();

    if ext.ends_with(".zip") || ext.ends_with(".tmp") {
        // Windows / macOS: ZIP 格式
        extract_from_zip(archive_path, bin_dir)
    } else {
        // Linux: tar.xz 格式
        extract_from_tar_xz(archive_path, bin_dir)
    }
}

fn extract_from_zip(zip_path: &PathBuf, bin_dir: &PathBuf) -> Result<(), String> {
    let file = std::fs::File::open(zip_path)
        .map_err(|e| format!("打开压缩包失败: {e}"))?;
    let mut archive = zip::ZipArchive::new(file)
        .map_err(|e| format!("解析 ZIP 失败: {e}"))?;

    let target_name = if cfg!(target_os = "windows") { "ffmpeg.exe" } else { "ffmpeg" };

    for i in 0..archive.len() {
        let mut entry = archive.by_index(i)
            .map_err(|e| format!("读取条目失败: {e}"))?;
        let name = entry.name().to_string();

        // 在压缩包中找到 ffmpeg 可执行文件（可能在子目录里）
        if name.ends_with(target_name) && !name.contains("ffprobe") && !name.contains("ffplay") {
            let dest = bin_dir.join(target_name);
            let mut out = std::fs::File::create(&dest)
                .map_err(|e| format!("创建文件失败: {e}"))?;
            std::io::copy(&mut entry, &mut out)
                .map_err(|e| format!("解压失败: {e}"))?;
            return Ok(());
        }
    }

    Err("压缩包中未找到 ffmpeg 可执行文件".to_string())
}

#[cfg(target_os = "linux")]
fn extract_from_tar_xz(tar_path: &PathBuf, bin_dir: &PathBuf) -> Result<(), String> {
    // Linux: 用 tar 命令解压，提取 ffmpeg 二进制
    let status = std::process::Command::new("tar")
        .args(["xf", &tar_path.to_string_lossy(), "--wildcards", "*/ffmpeg", "-C", &bin_dir.to_string_lossy(), "--strip-components=1"])
        .status()
        .map_err(|e| format!("tar 执行失败: {e}"))?;

    if !status.success() {
        return Err("tar 解压失败".to_string());
    }
    Ok(())
}

#[cfg(not(target_os = "linux"))]
fn extract_from_tar_xz(_: &PathBuf, _: &PathBuf) -> Result<(), String> {
    Err("当前平台不支持 tar.xz 解压".to_string())
}
```

### 3.3 video/session.rs — 帧捕获会话

与 `gif/frame.rs` 几乎完全一致，区别在于：不喂入 GifEncoder，而是将每帧保存为 PNG 文件。

```rust
// video/session.rs

use std::path::PathBuf;
use std::sync::atomic::{AtomicU8, Ordering};
use std::sync::Arc;
use std::thread;
use std::time::{Duration, Instant};

use crate::snap::capture;

const STATE_RECORDING: u8 = 0;
const STATE_PAUSED: u8 = 1;
const STATE_STOPPED: u8 = 2;
const PAUSE_SLEEP_MS: u64 = 50;

pub struct VideoRecordingSession {
    state: Arc<AtomicU8>,
    handle: Option<thread::JoinHandle<Result<(PathBuf, u32), String>>>,
}

impl VideoRecordingSession {
    /// 启动帧捕获线程
    /// 返回 (临时目录路径, 实际捕获帧数)
    pub fn start(
        x: u32, y: u32, width: u32, height: u32,
        fps: u16, max_duration_secs: u64,
        tmp_dir: PathBuf,
    ) -> Result<Self, String> {
        std::fs::create_dir_all(&tmp_dir)
            .map_err(|e| format!("创建临时目录失败: {e}"))?;

        let state = Arc::new(AtomicU8::new(STATE_RECORDING));
        let state_clone = state.clone();

        let handle = thread::spawn(move || {
            let frame_interval = Duration::from_millis(1000 / fps as u64);
            let max_duration = Duration::from_secs(max_duration_secs);
            let start_time = Instant::now();
            let mut frame_count: u32 = 0;

            loop {
                let current_state = state_clone.load(Ordering::Relaxed);
                if current_state == STATE_STOPPED { break; }
                if start_time.elapsed() >= max_duration { break; }

                if current_state == STATE_PAUSED {
                    thread::sleep(Duration::from_millis(PAUSE_SLEEP_MS));
                    continue;
                }

                let frame_start = Instant::now();
                frame_count += 1;

                match capture::capture_region(x, y, width, height) {
                    Ok(image) => {
                        let frame_path = tmp_dir.join(format!("frame_{:06}.png", frame_count));
                        if let Err(e) = image.save(&frame_path) {
                            eprintln!("视频帧保存失败: {e}");
                            break;
                        }
                    }
                    Err(e) => {
                        eprintln!("视频截屏失败: {e}");
                        frame_count -= 1;
                        continue;
                    }
                }

                let elapsed = frame_start.elapsed();
                if elapsed < frame_interval {
                    thread::sleep(frame_interval - elapsed);
                }
            }

            Ok((tmp_dir, frame_count))
        });

        Ok(Self {
            state,
            handle: Some(handle),
        })
    }

    pub fn pause(&self) {
        self.state.store(STATE_PAUSED, Ordering::Relaxed);
    }

    pub fn resume(&self) {
        self.state.store(STATE_RECORDING, Ordering::Relaxed);
    }

    /// 停止录制，返回 (临时目录, 帧数)
    pub fn stop(&mut self) -> Result<(PathBuf, u32), String> {
        self.state.store(STATE_STOPPED, Ordering::Relaxed);
        self.handle
            .take()
            .ok_or_else(|| "录制已停止".to_string())?
            .join()
            .map_err(|e| format!("录制线程崩溃: {:?}", e))?
    }
}
```

### 3.4 video/encoder.rs — FFmpeg 编码

```rust
// video/encoder.rs

use std::path::PathBuf;
use std::process::Command;

use super::ffmpeg_manager::get_ffmpeg_path;

pub struct EncodeOptions {
    pub fps: u16,
    pub crf: u8,
    pub preset: String,
}

/// 调用 FFmpeg 将帧序列编码为 MP4
/// 返回输出文件路径
pub fn encode_video(
    tmp_dir: &PathBuf,
    output_path: &PathBuf,
    options: &EncodeOptions,
) -> Result<PathBuf, String> {
    let ffmpeg = get_ffmpeg_path();
    let input_pattern = tmp_dir.join("frame_%06d.png");

    let output = Command::new(&ffmpeg)
        .args([
            "-y",                                           // 覆盖输出
            "-framerate", &options.fps.to_string(),         // 输入帧率
            "-i", &input_pattern.to_string_lossy(),         // 输入帧序列
            "-c:v", "libx264",                              // H.264 编码器
            "-crf", &options.crf.to_string(),               // 质量因子
            "-preset", &options.preset,                     // 速度预设
            "-pix_fmt", "yuv420p",                          // 兼容性最好的像素格式
            "-movflags", "+faststart",                      // MP4 快速启动
            "-vsync", "cfr",                                // 恒定帧率，防止变速
            &output_path.to_string_lossy().to_string(),
        ])
        .output()
        .map_err(|e| format!("FFmpeg 执行失败: {e}"))?;

    if !output.status.success() {
        let stderr = String::from_utf8_lossy(&output.stderr);
        return Err(format!("FFmpeg 编码失败 (exit {}): {}", 
            output.status.code().unwrap_or(-1), stderr));
    }

    Ok(output_path.clone())
}

/// 清理临时帧文件
pub fn cleanup_temp_frames(tmp_dir: &PathBuf) {
    if tmp_dir.exists() {
        let _ = std::fs::remove_dir_all(tmp_dir);
    }
}
```

```rust
    app: AppHandle, region: Region, recording: State<'_, VideoRecordingState>,
) -> Result<(), String> {
    let wal = app.state::<WalLogger>();

    // 前置检查 FFmpeg
    if !ffmpeg_manager::is_ffmpeg_available() {
        return Err("ffmpeg_not_found".to_string());
    }

    let scale = get_scale_factor();
    let phys_x = (region.x as f64 * scale) as u32;
    let phys_y = (region.y as f64 * scale) as u32;
    let phys_w = (region.width as f64 * scale) as u32;
    let phys_h = (region.height as f64 * scale) as u32;

    let log_x = region.x;
    let log_y = region.y;
    let log_w = region.width;
    let log_h = region.height;

    wal.info("VIDEO", &format!(
        "开始录制 | logical={},{},{},{} | physical={},{},{},{} | scale={}",
        region.x, region.y, region.width, region.height,
        phys_x, phys_y, phys_w, phys_h, scale
    ));

    let config_manager = app.state::<ConfigManager>();
    let (fps, max_duration) = {
        let config = config_manager.config.lock().unwrap();
        (config.video_fps, config.video_max_duration_secs)
    };

    // 创建临时帧目录
    let timestamp = chrono::Local::now().format("%Y%m%d_%H%M%S");
    let tmp_dir = ConfigManager::base_dir()
        .join("tmp")
        .join(format!("video_{timestamp}"));

    let session = VideoRecordingSession::start(
        phys_x, phys_y, phys_w, phys_h,
        fps, max_duration, tmp_dir,
    )?;

    let mut guard = recording.session.lock().map_err(|e| e.to_string())?;
    *guard = Some(session);

    // 隐藏 overlay → 打开录制控制条（和 GIF 完全一致）
    let app_clone = app.clone();
    std::thread::spawn(move || {
        std::thread::sleep(std::time::Duration::from_millis(OVERLAY_HIDE_DELAY_MS));
        hide_overlay(&app_clone);
        std::thread::sleep(std::time::Duration::from_millis(OVERLAY_SETTLE_DELAY_MS));

        let bar_w = RECORD_BAR_WIDTH;
        let bar_h = RECORD_BAR_HEIGHT;
        let bar_x = (log_x as f64 + log_w as f64) - bar_w;
        let bar_y = log_y as f64 + log_h as f64 + RECORD_BAR_OFFSET_Y;

        // RecordBar: 通过 URL 参数告知前端当前是 video 模式
        let _ = WebviewWindowBuilder::new(
            &app_clone, "record-bar",
            WebviewUrl::App("index.html?view=record-bar&mode=video".into()),
        )
        .title("sip-cc recording")
        .transparent(true)
        .decorations(false)
        .always_on_top(true)
        .inner_size(bar_w, bar_h)
        .position(bar_x.max(0.0), bar_y)
        .build();

        let region_url = format!(
            "index.html?view=record-region&x={}&y={}&w={}&h={}",
            log_x, log_y, log_w, log_h
        );
        let region_result: Result<tauri::WebviewWindow<tauri::Wry>, _> = WebviewWindowBuilder::new(
            &app_clone, "record-region",
            WebviewUrl::App(region_url.into()),
        )
        .title("sip-cc region")
        .transparent(true)
        .decorations(false)
        .always_on_top(true)
        .position(log_x as f64, log_y as f64)
        .inner_size(log_w as f64, log_h as f64)
        .build();
        if let Ok(region_win) = region_result {
            let _ = region_win.set_ignore_cursor_events(true);
        }
    });

    Ok(())
}

#[tauri::command]
pub fn video_stop(app: AppHandle, recording: State<'_, VideoRecordingState>) -> Result<String, String> {
    let wal = app.state::<WalLogger>();
    let mut guard = recording.session.lock().map_err(|e| e.to_string())?;
    let mut session = guard.take().ok_or("没有进行中的录制")?;
    let (tmp_dir, frame_count) = session.stop()?;

    if frame_count == 0 {
        encoder::cleanup_temp_frames(&tmp_dir);
        return Err("没有捕获到任何帧".to_string());
    }

    // 通知前端：进入编码阶段
    let _ = app.emit("video-encoding", true);

    let config_manager = app.state::<ConfigManager>();
    let (fps, crf, preset) = {
        let config = config_manager.config.lock().unwrap();
        (config.video_fps, config.video_crf, config.video_preset.clone())
    };
    let save_dir = config_manager.get_save_directory();
    let output_path = save::generate_video_path(&save_dir);

    // 编码（在当前线程执行，因为是 Tauri async command）
    let result = encoder::encode_video(
        &tmp_dir,
        &output_path,
        &EncodeOptions { fps, crf, preset },
    );

    // 无论成功失败都清理临时帧
    encoder::cleanup_temp_frames(&tmp_dir);

    // 通知前端：编码结束
    let _ = app.emit("video-encoding", false);

    let path = result?;

    // 关闭录制窗口
    let app_clone = app.clone();
    std::thread::spawn(move || {
        std::thread::sleep(std::time::Duration::from_millis(WINDOW_CLOSE_DELAY_MS));
        close_floating_windows(&app_clone);
    });

    // 复制到剪贴板
    crate::output::clipboard::copy_file_to_clipboard(&path)?;

    wal.info("VIDEO", &format!(
        "录制完成 | frames={} | path={}",
        frame_count, path.to_string_lossy()
    ));
    Ok(path.to_string_lossy().to_string())
}

}
```

```typescript
    if (total > 0) {

      progressFill.style.width = `${percent}%`;
      progressText.textContent = `${percent}% (${(downloaded / 1024 / 1024).toFixed(1)}MB)`;

  });
```

## 九、风险应对

| 风险 | 影响 | 应对 |
|------|------|------|
| FFmpeg 主下载源不可用 | 无法下载 | 多镜像源自动切换 + 手动下载引导文案 |
| 公司内网限制外部下载 | 下载失败 | 错误信息附带手动下载说明："请从 https://ffmpeg.org 下载 ffmpeg 放入 ~/.sip-cc/bin/" |
| 临时帧占磁盘过大 | 长时间录制耗尽空间 | `video_max_duration_secs` 默认 300s 上限；帧写入失败立即停止 |
| macOS FFmpeg 无签名 | "无法验证开发者" | 自动 `xattr -cr` 清除隔离属性 |
| Windows 杀毒软件拦截 | 下载/执行被阻止 | 错误信息引导用户添加白名单 |
| 帧率与实际捕获速度不匹配 | 视频变速 | 使用 `-vsync cfr` 强制恒定帧率 |
| `reqwest` 增加包体积 | ~500KB | 可接受，远小于内嵌 FFmpeg |

## 十一、总结

本方案基于可行性分析的**方案 E（FFmpeg 按需下载）**决策，在 sip-cc 现有架构上以**最小侵入**方式实现视频录制能力：

- **Rust 端**：新增 `video/` 模块（3 个文件），90% 帧捕获逻辑复制自 `gif/frame.rs`，编码逻辑仅 `std::process::Command` 调用 FFmpeg
- **UI 端**：新增 3 个 TS 文件，选区 100% 复用 `SelectionOverlay`，RecordBar 小改支持双模式
- **零侵入**：现有 GIF/截屏功能完全不变，所有新字段有 serde default 保证向后兼容
- **安装包零膨胀**：FFmpeg 按需下载到用户目录，安装包大小不变
- **依赖最简**：仅新增 HTTP 下载和 ZIP 解压两类依赖，不引入任何编码库
