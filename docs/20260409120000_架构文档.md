# sip-cc 架构文档

## 项目概览

sip-cc 是一款跨平台轻量截屏 + GIF 录制工具，基于 Tauri v2（Rust 核心 + WebView UI）。

- **版本**：0.4.0
- **代码规模**：Rust ~1900 行 / TypeScript ~1000 行 / CSS ~400 行
- **支持平台**：Windows 10+、macOS 14+、Linux（webkit2gtk）

## 模块职责

### Rust 端

| 模块 | 文件 | 职责 | 核心依赖 |
|------|------|------|---------|
| **入口** | `lib.rs` | Tauri 初始化、全局状态注册、overlay 预创建、退出控制 | tauri |
| **托盘** | `tray.rs` | 系统托盘菜单构建、事件分发、关于/设置窗口创建 | tauri, rfd, open |
| **配置** | `config.rs` | AppConfig 结构体、JSON 持久化、首次初始化 | serde, dirs |
| **截屏命令** | `commands/snap_cmd.rs` | 截屏 IPC、overlay 窗口 show/hide、DPI 缩放 | xcap, image |
| **GIF 命令** | `commands/gif_cmd.rs` | 录制启停 IPC、RecordBar/Region 窗口管理 | gif/frame |
| **快捷键命令** | `commands/hotkey_cmd.rs` | 快捷键 CRUD IPC、热重载、录制状态查询 | config, keybinding |
| **快捷键监听** | `hotkey/register.rs` | 全局键盘监听、平台分发（rdev/CGEventTap）、崩溃重试 | rdev, core-graphics |
| **快捷键解析** | `hotkey/keybinding.rs` | 按键字符串解析、平台匹配、白名单、冲突检测 | — |
| **截屏引擎** | `snap/capture.rs` | xcap 全屏截取 | xcap |
| **裁剪** | `snap/crop.rs` | RGBA 图像区域裁剪 | image |
| **GIF 编码** | `gif/encode.rs` | gif crate 流式编码封装 | gif |
| **GIF 帧循环** | `gif/frame.rs` | 录制线程、帧捕获、暂停/继续/停止状态机 | snap, gif/encode |
| **文件保存** | `output/save.rs` | PNG 保存、文件名时间戳生成 | chrono, image |
| **剪贴板** | `output/clipboard.rs` | 跨平台剪贴板写入（图片/文件） | arboard, Win32, osascript |
| **WAL 日志** | `wal/logger.rs` | 日志先行写入、30 天清理 | chrono |

## 数据流

### 截屏流程

```
用户按 F1 (Windows) / ⌘⇧1 (macOS)
  │
  ▼
hotkey/register.rs: 监听线程捕获按键
  │
  ▼
commands/snap_cmd.rs: open_snap_overlay()
  ├─ 1. xcap 截取全屏 → 存入 ScreenBuffer（内存）
  ├─ 2. show overlay 窗口（复用预创建的隐藏窗口）
  └─ 3. emit("overlay-mode", "snap-overlay")
         │
         ▼
       main.ts: 收到事件 → mountSnapOverlay()
         │
         ▼
       用户鼠标框选 → 点击"保存"按钮
         │
         ▼
       snapBridge.ts → invoke("snap_region", { region })
         │
         ▼
commands/snap_cmd.rs: snap_region()
  ├─ 1. DPI 缩放：逻辑像素 × scale → 物理像素
  ├─ 2. 异步隐藏 overlay（独立线程，防止卡死）
  ├─ 3. 从 ScreenBuffer 裁剪
  ├─ 4. save_png() → 桌面/自定义目录
  ├─ 5. copy_image() → 剪贴板（PNG 格式）
  └─ 6. WAL 日志记录
```

### GIF 录制流程

```
用户按 F3 / ⌘⇧3
  │
  ▼
hotkey → gif_cmd::open_gif_overlay()
  ├─ emit("overlay-mode", "gif-overlay")
  └─ show overlay
       │
       ▼
     用户框选 → 点击"开始录制"
       │
       ▼
     gifBridge.ts → invoke("gif_start", { region })
       │
       ▼
gif_cmd::gif_start()
  ├─ 1. DPI 缩放
  ├─ 2. RecordingSession::start() → 启动录制线程
  │      └─ 循环：capture_primary_screen() → crop → encoder.add_frame()
  ├─ 3. 异步隐藏 overlay
  ├─ 4. 创建 RecordBar 窗口（录制区域右下角）
  └─ 5. 创建 RecordRegion 窗口（红色边框，鼠标穿透）
       │
       ▼
     用户点击"停止" / 按 Esc/Enter
       │
       ▼
     gifBridge.ts → invoke("gif_stop")
       │
       ▼
gif_cmd::gif_stop()
  ├─ 1. RecordingSession::stop() → 停止录制线程
  ├─ 2. 异步关闭 RecordBar + RecordRegion 窗口
  ├─ 3. copy_file_to_clipboard()
  │      ├─ Windows: Win32 CF_HDROP（粘贴为文件）
  │      └─ macOS: osascript POSIX file
  └─ 4. WAL 日志记录
```

### 快捷键热重载流程

```
用户打开「快捷键设置」WebView
  │
  ▼
HotkeySettings.ts: invoke("get_hotkeys") → 显示当前配置
  │
  ▼
用户修改快捷键 → 按键捕获 → 冲突检测 → 点击"保存"
  │
  ▼
invoke("set_hotkeys", { hotkeys })
  │
  ▼
hotkey_cmd::set_hotkeys()
  ├─ 1. Keybinding::parse() 校验每个快捷键
  ├─ 2. 更新 ConfigManager → 写入 config.json
  ├─ 3. reload_bindings() → 更新全局 BINDINGS（Arc<RwLock>）
  └─ 4. WAL 日志记录
       │
       ▼
     下次按键事件 → 监听线程读取新的 BINDINGS → 新快捷键生效
```

## 全局状态

| 状态 | 类型 | 管理方式 | 用途 |
|------|------|---------|------|
| `ConfigManager` | `Mutex<AppConfig>` | `app.manage()` | 配置读写 |
| `WalLogger` | `Mutex<File>` | `app.manage()` | 日志写入 |
| `RecordingState` | `Mutex<Option<RecordingSession>>` | `app.manage()` | GIF 录制会话 |
| `ScreenBuffer` | `Mutex<Option<RgbaImage>>` | `app.manage()` | 截屏预存图像 |
| `BINDINGS` | `Lazy<RwLock<HashMap>>` | 全局静态 | 快捷键动态绑定 |
| `SHOULD_EXIT` | `AtomicBool` | 全局静态 | 退出标志 |

## 窗口管理

| 窗口 | 标签 | 生命周期 | 说明 |
|------|------|---------|------|
| overlay | `"overlay"` | 启动时预创建，show/hide 复用 | 截屏/GIF 选区遮罩 |
| 录制控制条 | `"record-bar"` | 录制开始时创建，停止时销毁 | 暂停/停止/计时 |
| 录制区域框 | `"record-region"` | 录制开始时创建，停止时销毁 | 红色边框指示 |
| 快捷键设置 | `"hotkey-settings"` | 点击菜单创建，关闭时销毁 | 设置界面 |
| 关于 | `"about"` | 点击菜单创建，关闭时销毁 | 作者信息 |

**设计原则**：
- overlay 窗口复用（节省 WebView 创建开销 ~30-40MB）
- 其他窗口按需创建销毁
- 同标签窗口不重复创建（先检查 `get_webview_window`）

## 跨平台适配

| 能力 | Windows | macOS | Linux |
|------|---------|-------|-------|
| 快捷键监听 | `rdev::listen` | `CGEventTap`（原生） | `rdev::listen` |
| 默认快捷键 | F1/F3 | ⌘⇧1/⌘⇧3 | F1/F3 |
| 全屏遮罩 | `set_fullscreen(true)` | 窗口尺寸覆盖屏幕 | `set_fullscreen(true)` |
| 截屏剪贴板 | arboard (RGBA) | osascript (PNG) | arboard (RGBA) |
| GIF 剪贴板 | Win32 CF_HDROP | osascript POSIX file | 路径文本 |
| 辅助功能权限 | 不需要 | 需要（自动弹窗引导） | 不需要 |
| DPI 缩放 | `xcap::Monitor::scale_factor()` | 同左 | 同左 |

**平台判断方式**：Rust 用 `cfg!(target_os = "...")` 编译期分发。

## 已知技术债

| 优先级 | 问题 | 位置 | 影响 |
|--------|------|------|------|
| 高 | SnapOverlay 和 GifOverlay 90+ 行重复代码 | ui/views/ | 维护成本 |
| 高 | 18 处 `.lock().unwrap()` 无错误恢复 | 多个 .rs 文件 | Mutex 毒化时 panic |
| 高 | 魔法值散落各处（延迟时间、窗口尺寸、颜色） | 全局 | 可读性差 |
| 中 | Windows 剪贴板用 unsafe Win32 API | clipboard.rs | 内存安全风险 |
| 中 | macOS keycode 映射不完整（缺 PrintScreen 等） | keybinding.rs | 部分按键无法绑定 |
| 中 | GIF 录制每帧截全屏再裁剪（xcap 支持 capture_region） | gif/frame.rs | 性能浪费 |
| 中 | 配置文件无范围校验（gif_fps 可设为 1000） | config.rs | 资源滥用 |
| 低 | 无单元测试 | — | 回归风险 |
| 低 | CSS 魔法值未用 CSS 变量 | overlay.css | 主题扩展性差 |
| 低 | navigator.platform 已废弃 | HotkeySettings.ts | 平台检测不准 |
