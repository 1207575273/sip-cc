# sip-cc 设计文档

## 概述

一款跨平台轻量截屏 + GIF 录制工具，类似 Snipaste 但支持 GIF 录制。

**核心约束**：
- 内存占用 < 50MB
- Windows 双击即用（单文件 .exe），macOS/Linux 同理
- 跨平台：Windows（WebView2）、macOS（WKWebView）、Linux（webkit2gtk）

## 技术选型

**架构**：Tauri v2（Rust 核心 + WebView UI）

| 功能 | 依赖 |
|------|------|
| 应用框架 | tauri v2 |
| 屏幕捕获 | xcap |
| GIF 编码 | gif crate（流式写入） |
| 全局快捷键 | rdev（强制抢占注册） |
| 系统托盘 | Tauri v2 内置 |
| 剪贴板 | arboard |
| 配置持久化 | serde + serde_json |
| 图像处理 | image |
| 前端构建 | vite + TypeScript |
| 前端框架 | 无（原生 DOM） |

## 功能清单

### 截屏
- 快捷键 F1 或托盘菜单触发
- 两种选区模式：全屏遮罩框选 / 可拖拽矩形框（设置可切换）
- 截取后自动复制到剪贴板 + 保存文件

### GIF 录制
- 快捷键 F3 或托盘菜单触发
- 同上两种选区模式
- 选区确认后显示录制控制条：暂停(Space) / 停止(Esc|Enter) / 计时器
- 录制完成后自动复制到剪贴板 + 保存文件

### GIF 内存控制策略
- 默认帧率：10fps
- 颜色量化：每帧 256 色
- 边录边编码：流式写入 GIF 文件，内存中只保留当前帧 + 前一帧（差分优化）
- 最大时长：3 分钟

| 功能 | 快捷键 |
|------|--------|
| 截屏 | F1 |
| GIF 录制 | F3 |

## 架构分层

```
系统托盘 (Tray)
       │ 触发
Tauri Core (Rust)
  ├─ commands/     IPC 命令层（Web 调用入口）
  ├─ snap/         截屏引擎
  ├─ gif/          GIF 录制引擎
  ├─ hotkey/       全局快捷键
  └─ output/       文件保存 + 剪贴板
       │ IPC (Tauri Commands)
WebView UI 层
  ├─ views/        选区遮罩、录制控制条
  ├─ bridge/       IPC 通信桥接
  └─ shared/       公共工具
```

每层只依赖下层，不反向依赖。commands/ 作为 Rust 侧门面层。

## 交互流程

### 截屏流程
1. 用户按 F1 或点击托盘"截屏"
2. 模式A：Rust 截取全屏暂存 → 创建透明全屏窗口 → 用户框选 → 坐标发给 Rust → 裁剪 → 剪贴板+保存
3. 模式B：弹出可拖拽矩形框 → 用户调整 → Enter 确认 → Rust 截取该区域 → 剪贴板+保存

### GIF 录制流程
1. 用户按 F3 或点击托盘"录制GIF"
2. 同上两种模式选定区域
3. 区域确认后显示 RecordBar 控制条
4. Rust 启动录制线程，按帧率截取选区，流式写入 GIF
5. Space 暂停/继续，Esc/Enter 停止
6. 停止后完成编码 → 剪贴板+保存 → 关闭控制条

## 持久化目录

所有持久化数据统一存放在 `~/.sip-cc/` 目录下：

```
~/.sip-cc/
├── config.json          # 应用配置
├── logs/                # WAL 日志目录
│   ├── 20260406143025.log
│   ├── 20260406150812.log
│   └── ...
└── output/              # 默认截图/GIF 输出目录（save_dir=default 时）
```

### 配置文件

`~/.sip-cc/config.json`：

```json
{
  "selection_mode": "overlay",
  "save_dir": "desktop",
  "custom_save_dir": null,
  "auto_start": false,
  "gif_fps": 10,
  "gif_max_duration_secs": 180
}
```

## WAL 日志机制

采用 WAL（Write-Ahead Logging）日志先行策略，所有关键操作在执行前先写入日志。

### 设计原则
- **先写日志，后执行操作**：截屏/录制/配置变更等操作，先将意图写入日志文件，再执行实际操作
- **操作可追溯**：每条日志记录操作类型、时间、参数、执行结果
- **崩溃恢复依据**：异常退出后可通过日志判断最后一次操作状态

### 日志文件
- 存放目录：`~/.sip-cc/logs/`
- 命名规则：`yyyyMMddHHmmss.log`（精确到秒），每次应用启动创建一个新日志文件
- 格式：每行一条记录，结构化文本

### 日志格式

```
[2026-04-06 14:30:25.123] [INFO] [SNAP] 开始截屏 | region=100,200,800,600 | mode=overlay
[2026-04-06 14:30:25.456] [INFO] [SNAP] 截屏完成 | path=/home/user/Desktop/sip-cc_snap_20260406_143025.png | size=1.2MB
[2026-04-06 14:30:30.000] [INFO] [GIF] 开始录制 | region=100,200,800,600 | fps=10
[2026-04-06 14:30:35.000] [INFO] [GIF] 录制暂停 | elapsed=5s | frames=50
[2026-04-06 14:30:40.000] [INFO] [GIF] 录制继续
[2026-04-06 14:31:00.000] [INFO] [GIF] 录制停止 | path=/home/user/Desktop/sip-cc_gif_20260406_143030.gif | elapsed=25s | frames=200
[2026-04-06 14:31:05.000] [INFO] [CONFIG] 配置变更 | key=selection_mode | old=overlay | new=drag_region
[2026-04-06 14:31:05.000] [ERROR] [SNAP] 截屏失败 | reason=no primary monitor found
[2026-04-06 14:31:10.000] [INFO] [APP] 应用启动
[2026-04-06 14:32:00.000] [INFO] [APP] 应用退出
```

### 记录的操作类型
| 标签 | 触发时机 |
|------|---------|
| `[APP]` | 应用启动、退出 |
| `[SNAP]` | 截屏开始、完成、失败 |
| `[GIF]` | 录制开始、暂停、继续、停止、失败 |
| `[CONFIG]` | 配置变更（字段、旧值、新值） |
| `[HOTKEY]` | 快捷键触发 |
| `[TRAY]` | 托盘菜单操作 |

### 日志清理
- 保留最近 30 天的日志文件
- 每次应用启动时清理过期日志

## 跨平台说明

| 平台 | WebView | 便携性 |
|------|---------|--------|
| Windows 10+ | WebView2（系统自带） | 双击 .exe 即用 |
